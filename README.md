# 🎬 ربات دوبله همزمان ویدیوهای یوتیوب به فارسی (YouTube AI Dubber)

این پروژه یک اپلیکیشن تحت وب هوشمند با فریم‌ورک **Streamlit** است که زیرنویس ویدیوهای یوتیوب را دریافت کرده، به فارسی ترجمه می‌کند و به صورت همزمان یا فایل MP3 یکپارچه با گوینده مصنوعی دوبله می‌نماید.

## ✨ قابلیت‌ها

- 🎙️ دوبله زنده و همزمان ویدیوهای یوتیوب با گوینده فارسی نیورال
- ⏱️ هماهنگ‌سازی زمان‌بندی (Sync) بر اساس زمان واقعی زیرنویس ویدیو
- 📥 امکان ساخت و دانلود یک‌جای کل فایل صوتی MP3 برای ویدیوهای طولانی
- ⏸️ قابلیت کنترل پخش و توقف (Pause / Resume)

## 🛠️ تکنولوژی‌های استفاده شده

- **Python 3.14**
- **Streamlit** (رابط کاربری وب)
- **Edge-TTS** (موتور تولید صدای فارسی نیورال)
- **Deep Translator** (موتور ترجمه)
- **YouTube Transcript API** (استخراج زیرنویس)

## 🚀 نحوه اجرای پروژه روی سیستم

```bash
pip install -r requirements.txt
streamlit run app.py
```
